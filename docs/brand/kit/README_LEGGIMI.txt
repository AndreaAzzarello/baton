BATON - KIT LOGO / BRAND KIT
===================================

Il kit raccoglie il logo Baton selezionato (B con freccia verso il basso),
le versioni operative per Windows/browser e le tavole delle bozze precedenti.

CONTENUTO

01_Logo_SVG/       SVG vettoriali scalabili: simbolo, logo orizzontale,
                   verticale, icona app e versioni monocromatiche.
02_Logo_PNG/       PNG su sfondo trasparente, ad alta risoluzione.
03_Icone_Windows/  File .ico multirisoluzione e PNG 16-512 px.
04_Icone_Browser/  File PNG 16/32/48/128 px per estensione browser.
05_Tavole_originali/ Tutte le tavole originali generate nel progetto.
06_Anteprime/      Tavola finale scelta e anteprima del pacchetto.

USO SUGGERITO

App WPF/Windows: 03_Icone_Windows/BATON_windows.ico
Browser extension: 04_Icone_Browser/baton_extension_*.png
Sito/GitHub: 01_Logo_SVG/BATON_logo_orizzontale_scuro.svg
Sfondo scuro: 01_Logo_SVG/BATON_logo_orizzontale_bianco.svg
Solo simbolo: 01_Logo_SVG/BATON_simbolo_color.svg

NOTA IMPORTANTE
Gli SVG sono ricostruzioni vettoriali pulite del concept visivo approvato,
realizzate dalla tavola PNG, non un sorgente SVG originale del generatore.
L'aspetto può presentare piccole differenze rispetto all'immagine originale.
L'originale raster selezionato e' incluso come TAVOLA_SCELTA_LOGO_BATON.png.
La leggibilità a 16x16 va sempre controllata in Windows e nei browser reali.
